# Tools and access

**Rule: you get the access your current task needs, and it is removed when you no longer need it.** Access is cheap to add back and expensive to lose track of.

## Slack

`neurotechx.slack.com` is where the community and the volunteers talk. Anyone can join from [neurotechx.org/community](https://neurotechx.org/community). Project channels may be private; your lead adds you. If you are made an owner or admin, turn on two-factor authentication.

## GitHub

Code, the website and these manuals live in the [NeuroTechX GitHub organization](https://github.com/NeuroTechX).

- **Public repositories need no invitation.** Fork, branch and open a pull request.
- **Regular contributors** are added to a team for their project, which gives write access to those repositories.
- **Private repositories are the exception.** Each person with access to a private repository takes a **paid seat**, so we add people to one only when the work requires it, and remove them when it ends.
- Turn on two-factor authentication on your GitHub account.

## Google Workspace

NeuroTechX uses Google Workspace: mail, Drive, Calendar, Meet.

- **Shared folders** for your project are shared with you directly.
- **A NeuroTechX address** ([you@neurotechx.org](mailto:you@neurotechx.org)) is created when your role means writing to people outside NeuroTechX on its behalf: partners, sponsors, speakers, chapters. It belongs to NeuroTechX, is used only for NeuroTechX work, and is closed or handed over when you leave. Turn on 2-Step Verification the day you get it.
- **Role mailboxes** (info@, chapters@ …) are shared by the people in that role. See [How NeuroTechX is organized](/handbook/organization).

> **Draft.** Until now every volunteer was given a Workspace account first. The onboarding review proposes the role-based rule above; the Executive Director has not adopted it yet. An acceptable-use policy for accounts is also in draft.

## The website

[neurotechx.org](https://neurotechx.org) is built from the public repository `NeuroTechX/neurotechx-website`. Every pull request gets a preview link; merging to `main` publishes the site. Pages from [NTX-dockit](https://github.com/NeuroTechX/NTX-dockit) are copied to the site every night. Merges need the Executive Director's approval.

## The newsletter

The newsletter goes to about 8,000 subscribers. It is sent by the newsletter team only. Never export the subscriber list or add people to it who did not sign up themselves (see [Personal information](/handbook/privacy)).

## Passwords

- Never put a password in an email, a chat message, a document or a spreadsheet.
- Shared logins for organization accounts are given by the Executive Director. A shared password manager is being set up; until then, ask the ED.
- If you think a password or account has been exposed, tell the ED immediately (see [Personal information](/handbook/privacy)).
